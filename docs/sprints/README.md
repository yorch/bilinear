# Sprint Specs (historical)

These files are the build-time specifications for Sprints 1-14. Each one was
written before the sprint started and describes the intended scope; the
shipped implementation may differ in small ways.

**These docs are frozen.** For the current state of the codebase use:

- [`../IMPLEMENTATION_PLAN.md`](../IMPLEMENTATION_PLAN.md) — canonical status
  snapshot and per-sprint checklist (Sprint 15+ lives here instead of in a
  dedicated file per `IMPLEMENTATION_PLAN.md:28`)
- [`../PATTERNS.md`](../PATTERNS.md) — the conventions that settled out of
  these sprints
- [`../ARCHITECTURE.md`](../ARCHITECTURE.md) — architecture doc, updated per
  sprint
- [`../DATABASE_SCHEMA.md`](../DATABASE_SCHEMA.md) and
  [`../API_DESIGN.md`](../API_DESIGN.md) — aligned with `prisma/schema.prisma`
  and `src/server/graphql/schema.ts`

No sprint doc is created for Sprint 15+. New specs go straight into
`IMPLEMENTATION_PLAN.md` as sprint sections.
